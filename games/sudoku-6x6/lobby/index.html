How it works

1Every row, column and 2×3 block holds 1–6 exactly once
2Paper cells are fixed clues — everything else is yours to place
3Duel: you and the bot each own half the empty cells — first side done wins
4Wrong digits flash teal and cost you +2.5s in duels

How to playScan → place → clear the board.

1Scan the gridSix cells per row, six per column — fixed clues anchor every 2×3 block.
2Place what you knowTap a cell, tap a number. Duplicates light up instantly.
3Race the botDuel splits the empty cells — first side done wins, mistakes cost +2.5s.
4Chain your clearsTimed runs give 45 seconds — back-to-back grids build streaks.
