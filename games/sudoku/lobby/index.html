How it works

1Every row, column and 3×3 box holds 1–9 exactly once
2Paper cells are fixed clues — everything else is yours to place
3Pencil marks let you note candidates; toggle Notes (✏) to jot them
4Duel: you and the bot each own half the empty cells — first side done wins
